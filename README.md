# nanoamt

[![CI](https://github.com/sleepybishop/nanoamt/actions/workflows/ci.yml/badge.svg)](https://github.com/sleepybishop/nanoamt/actions/workflows/ci.yml)

Lightweight C implementation of Automatic Multicast Tunneling (AMT, [RFC 7450](https://www.rfc-editor.org/rfc/rfc7450)).

## Build

```sh
make
make check
```
